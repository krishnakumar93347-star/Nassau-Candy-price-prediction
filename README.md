This repository houses the code, analytical workflows, and documentation for an individual data analytics research project. It examines e-commerce sales performance, evaluates product profitability, and segments customers using Recency, Frequency, and Monetary (RFM) analysis.

The project follows a structured CRISP-DM methodology, integrating Python for automated data preprocessing and statistical analysis, Microsoft Excel for validation and spreadsheet modeling, and Microsoft Power BI for interactive business reporting.

🛠️ Tech Stack & Tools
Python: Pandas, NumPy, Matplotlib, Seaborn (Data cleaning, preprocessing, exploratory data analysis)

Microsoft Excel: Data validation, PivotTables, exploratory summaries

Microsoft Power BI: Data modeling, DAX measures, interactive dashboards
